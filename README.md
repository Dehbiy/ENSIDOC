## Développement local

```bash
# Installer uv si pas déjà fait
curl -LsSf https://astral.sh/uv/install.sh | sh

# Installer les dépendances
uv sync

# Lancer le serveur local
uv run mkdocs serve
# → http://127.0.0.1:8000
```
